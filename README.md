# Sobri — asistente personal de escritorio

Sobri es un asistente de voz y texto que funciona en tu propio ordenador con Windows.
Entre otras cosas, lleva las redes de tu música: prepara vídeos y Shorts de tus
canciones, hace el plan de publicación y sube a **tu propio canal de YouTube**.

## ▶ YouTube

Sobri usa los **Servicios de API de YouTube** (*YouTube API Services*).
Al usar sus funciones de YouTube aceptas las
[Condiciones del Servicio de YouTube](https://www.youtube.com/t/terms)
y la [Política de Privacidad de Google](https://policies.google.com/privacy).

- Solo trabaja con **tu propio canal**, con el permiso que tú das en la página oficial de Google.
- Marca siempre el contenido hecho con IA.
- Retira el permiso cuando quieras en <https://security.google.com/settings/security/permissions>.
